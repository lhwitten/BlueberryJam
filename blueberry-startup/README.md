# Blueberry Jam Startup

This project provides a simple way to start the Blueberry Jam application using a batch script.

## Prerequisites

Before running the batch script, ensure that you have the following installed:

- Anaconda or Miniconda
- The `blueberryjammin` conda environment created and set up with all necessary dependencies.

## Usage

To start the Blueberry Jam application, follow these steps:

1. Open a command prompt.
2. Navigate to the directory where the `start_blueberry.bat` file is located.
3. Run the batch script by typing:

   ```
   start_blueberry.bat
   ```

This will activate the `blueberryjammin` conda environment and execute the `main.py` script.

## Notes

- Make sure that the `blueberryjammin` environment is properly configured with all required packages.
- If you encounter any issues, check that your Anaconda installation is correctly set up and that the environment is active.
